# Music-Net: A Deep Convolutional Neural Network for Music Genre Classification from Audio Songs

##  🎵Overview
Music Genre Classification (MGC) is a complex audio analysis task characterized by diverse timbral patterns, rhythmic structures, harmonic variations, and temporal dynamics. Its subjective and heterogeneous nature makes accurate genre recognition particularly challenging. Mel Spectrograms, which represent audio signals in a perceptually meaningful time–frequency domain, offer valuable insights for genre classification due to their strong alignment with human auditory perception.

In this project, we introduce MG-Net, a hybrid deep learning framework that combines:

Convolutional Neural Networks (CNN) for spatial and spectral feature extraction.

Bidirectional Long Short-Term Memory (BiLSTM) and Bidirectional Gated Recurrent Units (BiGRU) for temporal pattern analysis.

Mel Spectrogram-based representation to enhance audio feature learning and classification accuracy.

## 📊Datasets
The model is evaluated on two benchmark music datasets:

GTZAN Dataset: A widely used benchmark dataset containing 1,000 audio tracks across 10 music genres.

ISMIR2004 Dataset: A standard dataset for Music Information Retrieval (MIR), featuring diverse genre-labeled audio samples.
## 🚀Performance Highlights

GTZAN Dataset: Achieved 95.7% accuracy, outperforming several baseline models.

ISMIR2004 Dataset: Achieved 93.2% accuracy, demonstrating strong generalization and robust performance across multiple music genres.
